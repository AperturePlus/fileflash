# fileflash Web

This frontend project uses Bun as both runtime and package manager.

## Prerequisites

- Bun 1.2+

## Install dependencies

```bash
bun install
```

## Start development server

```bash
bun run dev
```

## Type check

```bash
bun run check
```

## Build for production

```bash
bun run build
```

## Preview production build

```bash
bun run preview
```
