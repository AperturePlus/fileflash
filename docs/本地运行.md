# FileFlash 本地运行说明

后端通过 `pydantic-settings` 读取 **`app/src/.env`**（与 `app/src/.env.example` 对齐）。不要把 `.env` 放在仓库根目录；前端独立使用 `web/.env.development`。

## 1. 依赖服务（Docker）

在项目根目录执行：

```powershell
cd docker/postgresql-16
docker compose up -d

cd ../minio
docker compose up -d
```

- PostgreSQL：`localhost:5432`，用户 `admin`，密码 `psgl-ff-db`，数据库 `fileflash`（与 `FF_DB_URI` 一致）。
- MinIO：API `localhost:9000`，控制台 `localhost:9001`，账号 `admin` / `minio-admin`（与对象存储相关变量一致）。

**Redis**：可选。未启动 Redis 时应用会降级（限流大致放行），一般不影响联调。若需与示例一致，可在本机起 Redis，密码与 `REDIS_URL` 里一致即可。

首次使用 MinIO 时，在控制台创建 bucket **`fileflash`**（若应用未自动创建）。

## 2. 后端（`app/`）

1. 复制环境文件（若尚未存在）：

   ```powershell
   copy app\src\.env.example app\src\.env
   ```

2. 确认 **`JWT_SECRET_KEY`** 长度足够（建议 ≥32 字符），否则日志会有安全警告。

3. 使用 **`app` 目录下的虚拟环境**（不要用仓库根目录里另一个 `.venv`，否则会缺 `uvicorn` 等包）：

   ```powershell
   cd app
   uv sync
   ```

4. 启动 API（工作目录必须是 **`app`**，这样 `src` 才是包根）：

   ```powershell
   uv run python -m uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
   ```

   默认接口前缀一般为 `/api/v1`（以实际 `settings` 为准）。

## 3. PyCharm / IntelliJ 调试

1. **解释器**：指向 **`…\fileflash\app\.venv\Scripts\python.exe`**（Windows）。
2. **工作目录**：`…\fileflash\app`。
3. **运行方式**：模块 **`uvicorn`**，参数 **`src.main:app --host 0.0.0.0 --port 8000 --reload`**（不要把 `uvicorn` 写在「脚本路径」里又用错模块模式）。
4. 应用会从 **`app/src/.env`** 加载变量；也可在运行配置里指定 **Environment files** 指向该文件。

仓库根目录提供了共享运行配置：**`.run/FileFlash_API.run.xml`**，用 PyCharm 打开项目后可在运行配置列表中选择 **FileFlash API**（若模块名不一致，在 IDE 里改一下 Module/SDK 即可）。

## 4. 前端（`web/`）

项目使用 **Bun**（见 `packageManager`）。对接本地后端时保持 **`web/.env.development`** 中：

- `VITE_BASE_URL=http://localhost:8000/api/v1`
- `VITE_ENABLE_MOCKS=false`

启动：

```powershell
cd web
bun install
bun run dev
```

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| `No module named uvicorn` | 解释器是否选成 **`app\.venv`**？是否在 **`app`** 目录执行？ |
| 数据库连接失败 | Postgres 容器是否已启动？`FF_DB_URI` 是否与 compose 一致？ |
| 登录后部分接口 403 | 邮箱验证门禁：开发环境可看控制台/日志中的验证链接或 token。 |
| JWT 密钥过短警告 | 加长 `JWT_SECRET_KEY`。 |
| 前端操作正常但 Network 里没有 API | 多半 **`VITE_ENABLE_MOCKS` 未设为 `false`**，MockJS 在浏览器内拦截；同时确认 **`VITE_BASE_URL` 端口与后端一致（8000）**，改完后需 **重启 `bun run dev`**。 |
